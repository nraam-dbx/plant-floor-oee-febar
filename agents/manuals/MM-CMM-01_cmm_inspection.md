## Probe faults (failure code PROBE_FAULT)
**Symptoms:** probe collision alarm, repeatability check failure (> 2 µm), measurement-program aborts.
**Repair MM-CMM-01-R1 (1.5 h):** replace stylus (part CMM-STY-3); re-qualify probe on the reference sphere;
run the daily repeatability artifact before release. Inspection-cell downtime starves upstream release —
escalate if a CMM is down more than one shift.
